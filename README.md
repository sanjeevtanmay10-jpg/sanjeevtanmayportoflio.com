# Sanjeev Tanmay — Portfolio

Personal portfolio website of Sanjeev Tanmay, UX/UI designer based in Delhi, India.

The site is guided by **Sanju**, a scripted animated character who walks visitors through each section.

## Structure

- `index.html` — page markup
- `css/site.css` — styles
- `js/data.js` — projects and Sanju's lines
- `js/sanju.js` — Sanju's movement, face and voice
- `js/app.js` — sections, menu, intro, likes and reviews
- `img/` — images

It is a static site with no build step. Open `index.html` through any static server to run it locally.
